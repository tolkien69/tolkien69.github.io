Privacy Policy

Last updated: 2026-11-10

YT Publisher is a personal tool that uploads videos to the developer's own YouTube channel. Home

Data accessed

With the owner's authorization, the app uses the YouTube Data API to upload videos, set thumbnails, schedule publication, and add videos to playlists on the owner's own YouTube account.

Data storage

The OAuth token is stored only as a local file on the owner's own computer or in the owner's private repository secrets. No YouTube or Google user data is sent to, stored on, or shared with any server or third party operated by the developer.

Sharing

We do not sell, share or transfer Google user data to anyone. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
